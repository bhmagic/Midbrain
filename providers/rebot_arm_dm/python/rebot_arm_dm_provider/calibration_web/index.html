Measured arm pose

The solid arm is measured state. The desktop line belongs only to this local development application.

The desktop plane and simplified self-collision display are local diagnostics only. They do not approve a motion range or replace a cleared workspace and attended stop gate.

Manual joint testing

This utility does not estimate or write calibration parameters. Raw velocity mode is intentionally unavailable. Each slider is a pointer deadman; releasing anywhere immediately enters gravity-float and snaps the target back to the measured angle.

Use a mechanically supported arm for first hardware motion. Start with very small ranges. Low-kp MIT is prohibited. MIT spring stiffness uses the supplied working defaults; velocity damping may be low. POS_VEL and FORCE_POS remain velocity/torque capped by the provider.
