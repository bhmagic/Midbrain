1. Gripper vector profile

A profile maps the gripper's two effector-axis directions. Selecting one fills every editable vector component.

2. Motion profile

Motion and force defaults stay separate from geometry. Task values may override the selected profile within manifest bounds.

3. Object and world vectors

These are task-instance inputs, equivalent to the object/world vectors on the Slicing developer page.

4. Prepare and freeze

Preparation validates and freezes all vectors, profiles, calibration, and Provider identities. It may make the required controllers HOT and create a nonphysical preview, but it does not move the arm or gripper.
