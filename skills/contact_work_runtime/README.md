# Contact Work Skill runtime

This is shared finite execution support for task-specific Contact Work Skills;
it is not a discoverable Skill or a persistent hardware Provider.

It binds a complete plan to the current Contact Provider and assembly identity,
acquires the Manager's advisory arm authority record, embeds that lineage,
signs the exact result inside the Skill process, submits one sequence number at
a time, services the advisory lease during planned waits, and requests `RELAX`
in terminal cleanup.

Task-specific Skills own their plan constraints. This helper intentionally
does not expose a generic Agent tool for arbitrary poses, wrenches, joint locks,
or torque limits.
