# Archived Source

This directory contains source retained for code archaeology, not active
documentation or Agent discovery.

The legacy vegetable-cutting prototype is preserved because it exposed frame,
planning, authorization, and task-boundary problems that informed the current
architecture. Its general responsibilities have moved into smaller Providers,
Skills, controller paths, and contracts. Do not copy it into a new workflow or
treat it as a supported capability.

Completed task plans, old tutorials, and phase handovers are not retained in
the active tree. Use Git history when their original text is required.
